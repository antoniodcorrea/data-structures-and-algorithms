# Sum of the N Largest Elements

Given an unsorted list of integers `list` and an integer `n`, return the sum of its `n` largest
elements.

### Example 1:

- Input: `list = [17, 310, 32432, 3, 2, 317, 34, 108379]`, `n = 3`
- Output: `141128`

Explanation:

- The 3 largest elements are `108379`, `32432` and `317`, and their sum is `141128`.
