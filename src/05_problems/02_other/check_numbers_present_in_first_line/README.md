# Check Numbers Present in the First Line

Write a program that takes as input a list of integers in the first line, followed by one integer on
each new line. For each integer from the second line onwards, output `True` if that number is
present in the first line, and `False` otherwise.

### Example 1:

- Input:

  ```
  99 12 10 23
  23
  25
  99
  ```

- Output:

  ```
  True
  False
  True
  ```
